# Sprint 1 — Build System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace six hand-maintained HTML pages with templates generated from a single content source, producing output that behaves identically to what is live today.

**Architecture:** Jinja2 template inheritance. `templates/base.html` owns the `<head>`, nav, mobile drawer and footer — the only place they exist. Each page supplies a body block and a small set of chrome parameters (which nav link is active, what the nav CTA points at, whether a footer renders). `build.py` renders to `.html` at the repo root, which is what Cloudflare already serves. Output is committed; the deploy path does not change.

**Tech Stack:** Python 3.14, Jinja2 3.1, pytest 9, BeautifulSoup 4.15.

**Spec:** `docs/superpowers/specs/2026-10-15-services-restructure-design.md`

## Global Constraints

- Output is written **in place at the repo root** and committed. No `dist/`, no build command on Cloudflare.
- `functions/api/*.js`, `_headers`, `robots.txt`, `assets/`, `favicon.svg`, `og-image.jpg` are **not touched** by the build.
- Existing URLs are unchanged: `/`, `/About`, `/Services`, `/Projects`, `/BizCheck`, `/Contact`, `/404`.
- **No pricing appears anywhere on the site.** Standing constraint.
- Every generated file opens with `<!-- GENERATED by build.py from templates/… — do not edit directly -->`.
- Sprint 1 ships **zero visible change**. Any visible difference is a bug, not an improvement.
- Commits use the repo-configured identity; never rewrite `master` history.
- Run every Python and pytest command with `PYTHONUTF8=1` (the console is cp1252). Every file read/write passes `encoding="utf-8"` explicitly.
- Page titles use an **em dash (U+2014)**: `About — AYiN Advisors`. The `·` and `?` seen in console output are display artefacts.
- **Baselines are stored as `tests/baseline/<stem>.snap`, never `.html`.** Cloudflare Pages serves the repo root, so a committed `.html` baseline would publish a duplicate, indexable copy of every page.
- **All pages share one footer: the footer `BizCheck.html` has today.** The five other pages currently differ (no BizCheck links, plus a "Request a market brief" link). Unifying them is the one deliberate visible change in this sprint; the parity suite pins exactly that delta (Task 6).

## Review Focus

Seven things the spec requires that no single task's happy path exercises:

1. **BizCheck's Turnstile head latch must still execute before `api.js` loads.** The latch sets `window.__bcTurnstileReady`; `api.js` is `async` and can fire its callback first. If the template reorders head elements the widget silently never renders. Pinned in Task 6.
2. **`404.html` has no footer today.** A base template that always renders one would silently change it. Pinned in Task 4.
3. **Contact and BizCheck nav CTAs point to same-page anchors** (`#book`, `#submit`), not `Contact.html`, and BizCheck's is gold (`btn`) not white (`btn btn-white`). A template hardcoding the common case breaks two pages. Pinned in Task 3.
4. **Inline `<script>` and `<style>` blocks must survive byte-for-byte.** Contact has 2 styles and 3 scripts, BizCheck has 1 and 2, and they carry the Turnstile wiring. Jinja2 will treat `{{` or `{%` inside them as syntax if the body is rendered rather than inserted verbatim. Pinned in Task 5.
5. **A generated file that someone hand-edits loses the edit on next build.** The header comment warns, but nothing detects it. Pinned in Task 7.
6. **Six of seven pages load Google Fonts with `<link href="…" rel="stylesheet">` (href first).** An extractor that only recognises `<link rel="…">` silently drops it and the whole site falls back to system fonts. Pinned by the `head` parity key in Task 2 and by Task 5's extractor.
7. **Footers are not uniform today.** Task 6 must prove the unification changed exactly three links and nothing else.

```python
# tests/parity.py
import re
from bs4 import BeautifulSoup


def _norm(s: str) -> str:
    return re.sub(r"\s+", " ", s or "").strip()


def _head_children(soup) -> list:
    out = []
    for el in soup.head.find_all(True, recursive=False):
        if el.name == "title":
            continue
        if el.name == "meta" and (
            el.get("charset") is not None or el.get("name") in ("viewport", "description")
        ):
            continue
        if el.name == "link" and "canonical" in (el.get("rel") or []):
            continue
        attrs = tuple(sorted(
            (k, " ".join(v) if isinstance(v, list) else v) for k, v in el.attrs.items()
        ))
        out.append((el.name, attrs, _norm(el.decode_contents())))
    return out


def page_facts(html: str) -> dict:
    soup = BeautifulSoup(html, "html.parser")

    nav = [
        (a.get("href"), _norm(a.get_text()), " ".join(a.get("class", [])))
        for a in soup.select(".nav-links .nav-link")
    ]
    cta = soup.select_one(".nav-cta .btn")
    nav_cta = (
        cta.get("href"),
        _norm(cta.get_text()),
        " ".join(cta.get("class", [])),
    ) if cta else None

    drawer = [
        (a.get("href"), _norm(a.get_text()))
        for a in soup.select(".mobile-drawer a")
    ]

    footer = soup.select_one("footer.footer")
    desc = soup.select_one('meta[name="description"]')
    canon = soup.select_one('link[rel="canonical"]')

    return {
        "title": _norm(soup.title.string if soup.title else ""),
        "description": desc.get("content") if desc else None,
        "canonical": canon.get("href") if canon else None,
        "nav": nav,
        "nav_cta": nav_cta,
        "drawer": drawer,
        "has_footer": footer is not None,
        "footer_links": [
            (a.get("href"), _norm(a.get_text()))
            for a in footer.select("a")
        ] if footer else [],
        "footer_text": _norm(footer.get_text()) if footer else "",
        "assets": sorted({
            e.get("href") or e.get("src")
            for e in soup.select("link[href], script[src], img[src]")
            if (e.get("href") or e.get("src", "")).startswith(("assets/", "favicon", "og-"))
        }),
        "head": _head_children(soup),
        "inline_scripts": [s.get_text() for s in soup.find_all("script") if not s.get("src")],
        "inline_styles": [s.get_text() for s in soup.find_all("style")],
    }


def diff_facts(a: dict, b: dict) -> list[str]:
    return [
        f"{k}:\n  baseline={a[k]!r}\n  built   ={b[k]!r}"
        for k in a if a[k] != b[k]
    ]
```

  <a href="{{ n.href }}"{% if n.class %} class="{{ n.class }}"{% endif %}>{{ n.label }}</a>

- [ ] **Step 4: Write `build.py`**

```python
#!/usr/bin/env python3
"""Render the site from content/site.json + templates/ to .html at the repo root."""
import json
from pathlib import Path
from jinja2 import Environment, FileSystemLoader, select_autoescape

ROOT = Path(__file__).resolve().parent
PAGES = ["index", "About", "Services", "Projects", "BizCheck", "Contact", "404"]

env = Environment(
    loader=FileSystemLoader(ROOT / "templates"),
    autoescape=select_autoescape(enabled_extensions=(), default=False),
    keep_trailing_newline=True,
)


def load_site() -> dict:
    return json.loads((ROOT / "content" / "site.json").read_text(encoding="utf-8"))


def render_page(stem: str, body: str, head_extra: str = "", body_scripts: str = "") -> str:
    site = load_site()
    return env.get_template("base.html").render(
        site=site,
        page=site["pages"][stem],
        body=body,
        head_extra=head_extra,
        body_scripts=body_scripts,
        logo=env.get_template("_logo.html").render(),
        footer=env.get_template("_footer.html").render(site=site),
    )


def render_all() -> dict[str, str]:
    out = {}
    for stem in PAGES:
        parts = json.loads((ROOT / "templates" / "pages" / f"{stem}.json").read_text(encoding="utf-8"))
        out[stem] = render_page(
            stem,
            (ROOT / "templates" / "pages" / f"{stem}.body.html").read_text(encoding="utf-8"),
            parts.get("head_extra", ""),
            parts.get("body_scripts", ""),
        )
    return out


def main() -> None:
    for stem, html in render_all().items():
        (ROOT / f"{stem}.html").write_text(html, encoding="utf-8")
        print(f"  wrote {stem}.html")


if __name__ == "__main__":
    main()
```

Autoescape is **off**. Bodies are pre-authored HTML, not user input; escaping them would mangle every page.

import json, re
from pathlib import Path

ROOT = Path(__file__).resolve().parent
PAGES = ["index", "About", "Services", "Projects", "BizCheck", "Contact", "404"]
OUT = ROOT / "templates" / "pages"
OUT.mkdir(parents=True, exist_ok=True)

for stem in PAGES:
    src = (ROOT / "tests" / "baseline" / f"{stem}.html").read_text(encoding="utf-8")

    # head_extra is the whole head MINUS the five things base.html owns, verbatim and
    # in source order. Do not enumerate what to keep: six pages write their fonts link
    # as <link href=... rel="stylesheet"> and an allow-list regex silently drops it.
    head = src[src.index("<head>") + len("<head>"): src.index("</head>")]
    for pat in (
        r'<meta charset="[^"]*"\s*/?>',
        r'<meta name="viewport"[^>]*>',
        r'<title>.*?</title>',
        r'<meta name="description"[^>]*>',
        r'<link rel="canonical"[^>]*>',
    ):
        head = re.sub(pat, "", head, count=1, flags=re.S)
    head_extra = head.strip()

    body_start = src.index('<nav class="nav"')
    drawer_end = src.index("</div>", src.index('<div class="mobile-drawer"')) + len("</div>")
    tail = src.index('<script src="assets/site.js">')
    foot = src.find('<footer class="footer">')
    body_end = foot if foot != -1 else tail
    body = src[drawer_end:body_end].strip()

    after = src[tail + len('<script src="assets/site.js"></script>'): src.rindex("</body>")].strip()

    (OUT / f"{stem}.body.html").write_text(body + "\n", encoding="utf-8")
    (OUT / f"{stem}.json").write_text(
        json.dumps({"head_extra": head_extra, "body_scripts": after}, indent=2),
        encoding="utf-8")
    print(f"  {stem}: body={len(body)}  head_extra={len(head_extra)}  scripts={len(after)}")

def check() -> list[str]:
