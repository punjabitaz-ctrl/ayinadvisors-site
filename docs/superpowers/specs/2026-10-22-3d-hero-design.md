# Phase 2d: real 3D feel (owner picked option B, 2026-10-22)

Inspiration (checked live): belgradearbor.rs uses Three.js r184 + GSAP 3.15 + Lenis 1.3, layered parallax, shaped image reveals, a WebGL scene, and a slow preloader. We take the feel, NOT the weight: no preloader, no full-page WebGL, no video.

Owner words: "stop with the weird tilt, for a proper 3d interactive feel to the website". Card tilt is already removed (master 88334d4). Do not reintroduce any pointer tilt on cards or glyphs.

## Scope (B = A + WebGL hero)

1. **Smooth scroll site-wide**: Lenis (self-hosted, MIT), touch scrolling left native (`syncTouch:false`), disabled under `prefers-reduced-motion`, with working anchor links, skip link, keyboard scrolling, Tab-focus scroll-into-view (respect `scroll-padding-top`), find-in-page, and browser back/forward.
2. **Layered depth parallax**: GSAP + ScrollTrigger (self-hosted) for modest scroll-linked depth: hero text/stat layers move at different rates, the photograph cards (Partnerships proof photo, About/BizCheck photos) drift a few percent inside their frames, section headings lift slightly. Transform/opacity only. Replaces the hand-rolled `data-drift` for ripples only if simpler; otherwise leave drift alone. Off under reduced motion and in print.
3. **WebGL hero iris on Home** (Three.js, Home only): a real 3D AYiN iris: concentric rings at different depths (the eye/spring motif), thin gold lines (no solid fills over text), a pupil disc, a few ripple rings. Interactive: eased pointer parallax (camera/group, bounded), scroll-linked (as the hero scrolls out the rings spread in depth and fade), theme-aware (colours read from CSS variables `--accent-fill`, `--ink`, `--surface` at init and on `themechange`; re-tint without reloading). Replaces the existing 2D `#iris` canvas on Home when WebGL is available; the 2D canvas stays as the fallback.
4. Everything else on the site stays as is. No new pages.

## Technical decisions

- Three.js is NOT shipped whole. Make a small custom bundle with esbuild from `tools/hero3d/src/main.js` into `assets/hero3d.js` (tree-shaken: WebGLRenderer, Scene, PerspectiveCamera, ring/torus geometry, line or basic materials, Group, Color, Clock and what else is truly needed). The built bundle is COMMITTED (Cloudflare serves the repo root, no build command). Dev tooling lives in `tools/hero3d/` (own `package.json`, lockfile committed, `node_modules` git-ignored and robots-disallowed like other tools dirs); document the rebuild in DEPLOY.md and add a test that the committed bundle is not stale only if that is cheap (e.g. a hash recorded in a small json checked by the test; if esbuild cannot run in CI that test must skip cleanly with a reason, not fail).
- Vendor libs: `assets/vendor/lenis.min.js`, `gsap.min.js`, `ScrollTrigger.min.js` with their licence texts alongside (assets/vendor/LICENSES.md noting MIT for Lenis and the GSAP standard licence; flag in the report if the GSAP licence has any restriction relevant to a marketing site). Pin exact versions in a manifest; no CDN at runtime; CSP unchanged (`script-src 'self'` already covers them; verify in `_headers`).
- Loading: `defer` scripts; Lenis/GSAP on every page, `hero3d.js` only on Home and only when `WebGL` is available, the viewport is >= 720px wide, `(pointer: fine)` or hover-capable, no `prefers-reduced-motion`, and `navigator.connection.saveData` is not set. Otherwise the existing 2D hero runs exactly as today. Any exception in the 3D path must fall back to the 2D canvas and never break the page.
- Performance: render on demand (requestAnimationFrame runs only while pointer/scroll input is active or the camera is settling, then stops; no idle loop), device pixel ratio capped at 2, pause when the tab is hidden or the hero is off-screen, dispose GPU resources on teardown. Budgets: `hero3d.js` <= 200 KB gzipped, vendor libs total <= 120 KB gzipped, LCP unaffected (hero text must not wait for the bundle), no layout shift.
- Accessibility (binding): canvas is `aria-hidden` and decorative; text over it keeps the existing contrast tests green in BOTH themes (keep the hero vignette/overlay so contrast is measured on solid-ish background; pixel-contrast tests must pass with the canvas rendered); no motion that runs on its own for more than 5 s (WCAG 2.2.2): idle breathing, if any, stops after 5 s; pointer and scroll driven motion is user-initiated and fine; reduced motion = no Lenis, no parallax, no WebGL; no keyboard trap; Lenis must not break `scroll-padding-top` focus visibility, anchor links, skip link, or the mobile drawer; touch scroll untouched.
- Theme: colours come from theme CSS variables read at runtime (no colour literals in `hero3d.js` source beyond fallbacks listed in the colour-literal allowlist with a reason; prefer reading the variables and failing to a documented default only if missing). Update tests/color_literal_allowlist.json honestly.
- No em dashes anywhere (owner rule); no personal info in docs; docs are published.

## Tests to add (keep them cheap; run only these plus the Home axe tests during development, the controller runs the full suite once)

- Static: vendor files and licences exist; bundle size budgets; Home head loads `hero3d.js` and no other page does; no CDN origins; CSP covers the scripts; no colour literals; no em dash.
- Browser (Chromium; use `--use-gl=swiftshader` or the default headless WebGL; if WebGL is unavailable in the harness the 3D tests skip with a clear reason and the fallback tests still run): (a) with WebGL on desktop viewport the Home hero shows the WebGL canvas (flag attribute set by the script) and the 2D canvas is inactive; (b) fallbacks: reduced motion, narrow viewport, no WebGL (override `getContext`), and a thrown error in the 3D path each leave the 2D canvas running and the page error-free; (c) idle: after the pointer stops and the scroll settles, rAF callbacks stop within 3 s (count them); (d) pointer move changes the scene transform within bounds, and a scroll changes the ring spread; (e) theme toggle re-tints (colour uniform/material colour changes); (f) Lenis: anchor jump to an in-page id lands the target below the sticky nav, Tab into an off-screen link scrolls it into view clear of the nav, skip link works, `Home`/`End`/PageDown keys scroll, reduced motion disables Lenis; (g) no horizontal scroll at 320 and 1280; (h) axe and pixel-contrast for Home in light and dark with the canvas present.

## Out of scope

Preloader, video hero, full-page WebGL, shader transitions between pages, 3D on other pages, tilt of any kind.
